Idea exchange · what I want your eye on

The mock encodes the interview decisions. The five points below are where a different call changes the build.

A Rolling window bar

24 cells, one per 7-day window. Warning cells are where min is missed. Is this readable enough, or would you rather see only the flagged windows as chips?

B Month strip

One cell per day, outlined cells are duties already on the roster. This is the fastest way to sanity-check "FLY first, then RES, then DO into leftovers".

C DO with no free day

Sep 23–29 shows the honest failure: FLY filled every day, so DO min is reported, not forced. Alternative is to reserve one day per window before FLY, which you declined.

D Add duty type

Dropdown at assignment_group level (GRD, LVE, TRN, SIM…). Ground-only groups get no pool and are placed like DO.

E Multi-crew

With several crew selected, screen 2 repeats the per-crew block top to bottom, same order as the roster pane. Pool in screen 1 shows the union.
