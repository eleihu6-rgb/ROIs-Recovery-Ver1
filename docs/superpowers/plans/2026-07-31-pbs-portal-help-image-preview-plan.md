# PBS Portal Help 图片全屏预览实施计划

1. 新增独立 `HelpImagePreview`。
   - 使用 `AppDialog` 提供模态能力，仅在当前实例隐藏标题栏；图片视口填满窗口，右上角只保留悬浮关闭按钮。
   - 保留滚轮缩放、拖动、键盘平移、`0` 重置和焦点管理，不显示独立工具栏。
2. 将 `HelpScreenshot` 改为可访问的预览触发器。
   - 仅图片加载成功后允许打开，失败时保留现有占位。
3. 增加 Playwright 图片预览交互回归并更新人工测试。
   - 覆盖无标题栏/工具栏、悬浮关闭、50%–400%、拖动、键盘、重置、焦点恢复和两个视口。
4. 运行 Help E2E、ESLint、TypeScript、生产构建、UI 门禁和 GitNexus 改动检查。
