# Pairing 搜索分页回顶测试

## 前置条件

- 进入 `Bid > Search Pairings`。
- 搜索结果至少有两页，且单页内容能够产生内部滚动条。

## 页码切换

1. 将右侧结果列表滚动到底部。
2. 分别使用下一页、上一页、具体页码和输入页码后按 Enter 切换页面。

预期：每次有效切页后，右侧结果列表立即回到顶部；浏览器页面和左侧 Bidding Calendar 位置不变。

## 每页数量

1. 将结果列表滚动到底部。
2. 修改 `30/Page` 等每页数量选项。

预期：结果列表立即回到顶部，并保持现有回到第 1 页的行为。

## 边界场景

- 点击当前页或输入当前页：不产生额外滚动。
- 输入超出范围的页码：沿用现有页码归一化规则，并在发生有效页码变化时回顶。
- 第一页的上一页、最后一页的下一页保持禁用。

## 回归范围

- Pairing 搜索分页请求与页码状态。
- 结果列表内部滚动。
- Date Range、Pairing Number、Airport 和时间筛选状态。
- 左侧 Bidding Calendar 状态。
