# PBS 机场选择下拉缩放适配测试

## 前置条件

- 使用可进入 PBS Portal 的测试账号。
- Bid 和 Standing Bid 页面可正常加载。
- Pairing 属性目录包含 `Airport Preference`。
- 机场选项接口至少返回一个可选机场。

## 用例一：Bid 页面缩放适配

1. 将浏览器视口设置为 `1000 × 862`。
2. 进入 `Bid`，切换到 `PAIRING`。
3. 新增 `Airport Preference`。
4. 点击 `AIRPORTS` 选择框。

预期结果：

- 下拉框与配置弹窗保持相同缩放比例，不会突然放大。
- 下拉框左右边界均在视口内。
- 下方空间不足时，下拉框自动向上展开。
- 机场列表内容过多时，只在列表内部滚动。

## 用例二：Standing Bid 页面缩放适配

1. 将浏览器视口设置为 `1366 × 700`。
2. 进入 `Standing Bid`。
3. 新增 `Airport Preference`。
4. 点击 `AIRPORTS` 选择框。

预期结果：

- 下拉框尺寸与 Standing Bid 配置弹窗一致。
- 下拉框完整位于视口范围内。
- 可正常筛选、选择和取消选择机场。

## 用例三：键盘关闭

1. 打开机场选择下拉框。
2. 将焦点放在筛选输入框、机场选项或 `Clear all` 按钮上。
3. 按 `Esc`。

预期结果：

- 只关闭机场选择下拉框。
- 外层属性配置弹窗保持打开。
- 焦点回到机场选择框。

## 边界与回归范围

- 验证 `1920 × 1080`、`1366 × 700`、`1000 × 862` 三种视口。
- 验证下拉框向上和向下两种展开方向。
- 验证 Landing、Layover、Both 三种机场事件。
- 回归 Work Start Station 等复用通用机场多选组件的属性。
- 回归点击外部关闭、搜索筛选、单项选择、取消选择和 `Clear all`。
