# PBS Portal 顶部导航 overflow 菜单回归测试

## 前置条件

- PBS Portal 可正常访问。
- 使用有效员工账号登录。
- 浏览器宽度调整到约 `940px`，确保顶部导航右侧菜单项被收进三个点按钮。

## 操作步骤

1. 打开 PBS Portal 登录页并登录。
2. 进入 `Dashboard`。
3. 观察顶部导航中是否出现三个点 `More navigation` 按钮。
4. 将鼠标移动到三个点按钮上。
5. 点击三个点按钮。
6. 在弹出的菜单中点击 `Help`。
7. 在正常宽度和窄屏宽度下观察顶部导航右侧 action 区域。

## 预期结果

- 三个点按钮 hover 时显示小手光标。
- 点击三个点按钮后，overflow 菜单正常显示，不被顶部导航裁剪。
- 菜单中显示被收起的导航项，例如 `Standing Bid`、`Help`。
- 点击 `Help` 后页面跳转到 Help，并且 overflow 菜单关闭。
- 未启用的 `Notifications` 小铃铛和 `Settings` 齿轮不应显示。
- `Log out`、头像、用户名仍正常显示；开发环境下 `UI Inspector` 仍按开关显示。

## 异常/边界场景

- 再次点击三个点按钮时，菜单应关闭。
- 点击菜单外区域或按 `Esc` 时，菜单应关闭。
- 调整窗口宽度后，菜单位置应跟随三个点按钮重新定位，不能漂移到错误位置。

## 回归范围

- PBS Portal 顶部导航。
- 窄屏/缩放状态下的导航 overflow 行为。
- 顶部导航右侧版本号、登出、头像区域不应与 overflow 菜单互相遮挡。
- 未启用 action 入口隐藏策略。
