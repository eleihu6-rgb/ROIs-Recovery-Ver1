Scenario Gantt — Optimized Duty Marker

Three mockups based on the current roster Gantt (Jun 2026). Solver-assigned / optimized duties today show a tiny yellow flash in the block corner — hard to scan across 70+ crew rows. Open each option in a new tab; compare at a glance.

Problem: The flash icon sits inside small DO / duty pills and competes with stars, pairing bars, and weekend shading. Planners need to spot which blocks came from the optimizer without squinting.
01
Left Stripe + OPT Pill
Amber left border on every optimized block; a readable OPT pill with flash icon sits below the assignment code. Non-optimized blocks unchanged.
Subtle scan · Bloomberg
02
Glow Halo + Large Badge
Optimized duties get a soft amber outer glow and a larger floating badge (⚡) that overlaps the block edge — visible even on narrow single-day cells.
High visibility
03
Row Rail + Connector
A thin amber rail in the timeline gutter links consecutive optimized days per crew; each day still shows a medium flash on the rail dot. Good for multi-day optimizer runs.
Pattern scan · multi-day
