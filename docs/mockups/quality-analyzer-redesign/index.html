Roster Quality Analyzer — Group by QLTY

Five mockups that flip the current crew-first table into rule-first grouping. Each shows how many crew are affected per QLTY rule and how to drill into details. Open any card in a new tab — click expand / tabs / cards to try interactions.

Redesign goals
  • Primary grouping = QLTY rule (1001 / 1002 / 1003), not crew row
  • Each group shows total crew count with that issue
  • View details — expand or navigate to see affected crew + date ranges
  • Keep: 147 crew summary, Issues-only filter, click crew → jump to Gantt row
01
Accordion Groups
Stacked QLTY sections with large count badges. Click header to expand inline crew table. Best when planners scan one rule at a time.
Dense · Familiar

Summary Cards + Panel
Three KPI cards across the top (crew count per rule). Selected card drives the detail panel below. Clear at-a-glance totals.

Master–Detail Split
Left nav lists QLTY rules with counts; right pane shows crew table for the selected rule. Efficient for comparing rules without scrolling past long accordions.
Split · Power-user

Tabbed Rules
Horizontal tabs — one per QLTY — with badge counts. Full-width crew detail table per tab. Minimal chrome, maximum table space.
Tabs · Table-first

Compact Matrix
Dense group header rows in a single scrollable table; "View N crew" expands nested sub-rows. Closest to current table density, inverted hierarchy.
