Crew App · Trip Details — shared duty title (Ver3)

One title per duty, shared by every segment in it. On a single-duty trip the hero is the shared title; on a multi-duty trip each duty card carries its own. Each segment below identifies itself only by index, flight number, route and block. Times stay in the compact 3-pair matrix — so a six-sector duty reads as one unit, not six repeated cards.

Theme
1 · One title per duty

PR1811 · 1812 · 1863 · 1864 · 1885 · 1886 and the full routing live once — in the hero for a single-duty trip, or on each duty card when a trip has several duties. Segment rows never repeat a trip/flight title.

2 · Two-row time matrix

Scheduled / Estimated / Actual are three columns; STD↔STA, ETD↔ETA, ATD↔ATA stack inside each. Two text rows per segment instead of three full-width rows.

3 · Duty totals once

FDP · DP · Block · Rest are reported on the shared duty card, so they never grow with the sector count.

4 · Calendar strip

The iPhone Calendar action stays a full-width strip under the hero — not a right-hand card.

1 · iPhone — compact (420 × 912)

Six-sector duty, one shared title. Each segment card carries only: index + flight + route + block, the 3-pair matrix, and one ops line. No date, fleet or trip title repeats on the segment cards.

2 · iPhone Duo inner screen — wide (951 × 669)

Same duty on the Duo inner screen. The shared title card is full width, and the six sectors become six table rows. The table fits without scrolling, so the whole duty is visible at once.

1
Title once, rows many

The hero is the shared title for this single-duty trip. The six rows only identify the sector; no row repeats the routing.

2
Pairs stay aligned

Scheduled / Estimated / Actual columns keep STD↔STA, ETD↔ETA, ATD↔ATA on the same row, so a delayed sector is read across, not up and down.

3
Ops on the second line

Boarding · door close · off-block and the gate/stand→belt path sit under each sector, still inside the same row.

4
Scales to six

Six rows cost the same height as one row on a long list; the duty card height does not grow with the sector count.

3 · Why shared title works better for a 6-sector duty

The comparison is about repetition, not about hiding information: every time and every segment stays visible.

Ver1 — title on every flight card

Six repeated headers: flight number, route, fleet and date appear six times.

Ver3 — one shared duty title

The hero states the title once; the duty card adds only report, markers and totals, then six compact rows.
