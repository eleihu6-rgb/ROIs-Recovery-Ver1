# Gantt 整体布局

## 界面结构

```
┌──────────────────────────────────────────────────────────────────┐
│ Header: [侧边栏] [日期范围] | [刷新][筛选] | [删除][Undo][Redo] │
│         [Save] | [缩放+/-] | [法规集合] | [Pane切换] | [主题]   │
├──────────────────────────────────────────────────────────────────┤
│ SummaryBar: 按任务类型统计当天人数，颜色块按百分比（50px 高）     │
├──┬──────────┬────────────────────────────────────────────────────┤
│  │ 占位260px│ TimeAxis: 共享时间轴（30px 高）                    │
├──┼──────────┼────────────────────────────────────────────────────┤
│  │ Crew 面板│ Roster 主 Pane（Canvas 甘特图）                    │
│  │ 双行显示 │                                                    │
├──┼──────────┼────────────────────────────────────────────────────┤
│  │ Crew 面板│ Roster 副 Pane（可隐藏）                           │
├──┼──────────┼────────────────────────────────────────────────────┤
│  │ Pairing  │ Pairing Pane                                      │
├──┼──────────┼────────────────────────────────────────────────────┤
│  │ Flight   │ Flight Pane                                       │
├──┴──────────┴────────────────────────────────────────────────────┤
│ HorizontalScrollbar                                              │
├──────────────────────────────────────────────────────────────────┤
│ StatusBar: hover 信息 | 法规集合名 | 违规数（可展开面板）         │
└──────────────────────────────────────────────────────────────────┘
```

## 布局规则

- 默认显示：Roster 主 Pane + Pairing Pane
- 四个 Pane 均可通过工具栏按钮独立显示/隐藏
- Pane 上下堆叠排列，可拖拽调整高度（6px 分隔条，最小高度限制）
- 所有 Pane 共享水平滚动（时间轴同步）

## 工具栏

### 按钮布局（从左到右）

| 组 | 按钮 |
|---|-------|
| 导航 | 日期范围选择器 |
| 操作 | 刷新、筛选 |
| 编辑 | 删除、Undo、Redo、Save（带操作计数 badge） |
| 缩放 | `+` / `-` |
| 法规 | 法规集合下拉选择器 |
| Pane 切换 | Roster Main/Sub、Pairing、Flight |
| 右侧 | 选中数、主题切换 |

### 交互规范

- 所有按钮统一 `h-7 w-7` 图标风格
- Tooltip 提示（含快捷键）
- `active:scale-95` 按下反馈
- 禁用态 `text-muted-foreground/30 pointer-events-none`

## 尺寸常量

| 常量 | 值 | 说明 |
|------|-----|------|
| ROW_HEIGHT | 43px | 每行高度 |
| HEADER_HEIGHT | 30px | 时间轴头部 |
| TASK_HEIGHT | 30px | 任务条高度 |
| TASK_PADDING | 6px | 任务条上下间距 |
| LEFT_PANEL_WIDTH | 260px | 左侧面板默认宽度 |
| SUMMARY_BAR_HEIGHT | 50px | 汇总条高度 |

## 快捷键

| 快捷键 | 操作 |
|--------|------|
| Ctrl+S | 保存所有待提交修改 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+Q | 从选中航班创建 Pairing |
| Del / Backspace | 删除选中 |
| Ctrl+Click | 多选（toggle） |
| Shift+Click | 范围选择（行选择模式） |
| Escape | 取消选中 / 关闭菜单 |
| Ctrl+/- | 缩放 |

工具栏有 ⌨️ 按钮打开快捷键参考面板（命令面板风格，按键用 `<kbd>` 物理按键样式）。

## 版本信息

主题切换下拉框顶部显示 git commit hash + 构建时间戳（`__APP_VERSION__`）。

## Pane 高度调整

- PaneSplitter 组件：6px 拖拽条
- 使用 ref 避免闭包过期，`getState()` 实时读取高度
- 最小高度：Roster 150px, Pairing/Flight 120px
