Data Flow — Timezone & Segment Mode

Timezone API

GET /api/base/timezone-options
[
  {
    "airport": "PEK",
    "airportName": "Beijing Capital",
    "zoneId": "Asia/Shanghai",
    "utcOffset": "+08:00",
    "isBase": true
  },
  { "airport": "SHA", "zoneId": "Asia/Shanghai",
    "utcOffset": "+08:00", "isBase": true },
  { "airport": "UTC", "zoneId": "UTC",
    "utcOffset": "+00:00", "isBase": false }
]
1. 读 dictionary(SYS_PARAM/DEFAULT_TIMEZONE).code_value → split('|')
2. JOIN airport ON airport.airport IN (codes) → zone_id, utcOffset
3. LEFT JOIN base → isBase flag
4. isBase=true 排在前面; UTC 固定追加

Pairing Segment API

GET /api/pairing/:id/segments
{
  "pairingId": "P0412",
  "windowStart": "2026-04-20T00:00:00Z",
  "duties": [
    {
      "dutySeq": 1,
      "pickup":  { "start":"...", "end":"..." },
      "brief":   { "start":"...", "end":"..." },
      "flights": [
        { "fltNum":"CA1201",
          "depArp":"PEK", "arvArp":"SHA",
          "schDepDtUtc":"...",
          "schArvDtUtc":"..." }
      ],
      "debrief": { "start":"...", "end":"..." },
      "dropoff": { "start":"...", "end":"..." }
    },
    { "dutySeq": 2, /* same shape */ }
  ],
  "layovers": [
    { "start": "dropoff[0].end",
      "end":   "pickup[1].start" }
  ],
  "rest": {
    "start": "dropoff[last].end",
    "end":   "pairingEndUtc"
  }
}
Connectivity guarantee enforced server-side:
dropoff[N].end === layover[N].start
layover[N].end === pickup[N+1].start
dropoff[last].end === rest.start
