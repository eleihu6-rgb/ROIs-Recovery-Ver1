## 1. 系统概述

### 1.1 项目目标

将运行 8 年的 JavaFX + Oracle 航空机组排班系统重建为现代化 Web 系统，支持：
- 多航司部署（零代码修改，仅配置差异）
- 实时排班 + 法规合规检查
- 自动配对优化（PO）+ 排班分配优化（RO）
- 机组偏好竞标（PBS）

### 1.2 五大功能模块

| 模块 | 代号 | 核心功能 | 使用频率 |
|------|------|---------|---------|
| Live Gantt | M1 | 实时排班操作界面（甘特图） | 每日高频 |
| Rule Engine | M2 | CCAR-121 法规合规检查 | 贯穿所有模块 |
| PO Optimizer | M3 | 航班→配对 自动组环优化 | 每月 3-5 天 |
| RO Optimizer | M4 | 配对→机组 自动分配优化 | 每月 3-5 天 |
| PBS | M5 | 机组偏好竞标系统 | 每月竞标期 |

### 1.3 业务背景

- 排班周期：月度排班（每月 20 号左右发布下月计划）
- 法规依据：CCAR-121-R5（中国民航法规）
- 机组类型：飞行员（CA/FO）+ 客舱乘务员（PU/FA）
- 排班模式：排班员手动调整 + 优化引擎自动生成

## 3. M1 Live Gantt 排班模块

> 最核心的高频操作模块，排班员每日使用

### 3.1 整体布局

系统采用多 Pane（面板）架构，从上到下依次为：

```
┌──────────────────────────────────────────────────────────┐
│ Header: 工具栏 + Pane 显隐按钮 + 缩放 + Undo/Redo      │
├──────────────────────────────────────────────────────────┤
│ SummaryBar: 按任务类型统计每天人数                        │
├────────────┬─────────────────────────────────────────────┤
│ 左侧面板   │ TimeAxis: 共享时间轴                        │
├────────────┼─────────────────────────────────────────────┤
│ Crew 信息  │ Roster 主 Pane（甘特图）                    │
├────────────┼─────────────────────────────────────────────┤
│ Crew 信息  │ Roster 副 Pane（可隐藏）                    │
├────────────┼─────────────────────────────────────────────┤
│ Pairing 信息│ Pairing Pane                               │
├────────────┼─────────────────────────────────────────────┤
│ Flight 信息│ Flight Pane                                 │
├────────────┴─────────────────────────────────────────────┤
│ HorizontalScrollbar: 横向滚动条（联动所有 Pane）          │
├──────────────────────────────────────────────────────────┤
│ StatusBar: hover 信息 + 时数统计 + 版本号                │
└──────────────────────────────────────────────────────────┘
```

### 3.2 四个 Pane 功能

#### 3.2.1 Roster 主 Pane（P0 必须）

- **用途**：显示机组排班甘特图，排班员主要操作界面
- **左侧固定列**：
  - 第一行：CrewId、Rank、Base
  - 第二行：CrewName、Fleet、YBH（年度飞行时数）
  - 支持 Seniority 指标：YBH/MBH/YAL/MAL/YDO/MDO
  - 列宽可拖拽调整，列顺序可配置，列可显示/隐藏
  - 点击列头排序（工具栏显示当前排序字段和方向）
  - 默认排序可按航司配置（有的按 CrewId，有的按 Rank）
- **右侧甘特图区域**：
  - 每行一个 Crew，显示其在日期范围内的所有任务
  - 飞行任务块：显示航班号 + 出发/到达站点 + 起止时刻
  - 地面任务块：显示任务类型代码（TRN/SBY/OFF 等）
  - 颜色按任务类型区分，用户可自定义颜色
  - 虚拟化渲染（支持 1000+ 机组）

#### 3.2.2 Roster 副 Pane（P0 必须）

- **用途**：提供第二个视角，方便不同排序/筛选下交换任务
- **特性**：与主 Pane 完全独立（独立筛选、独立排序、独立滚动）
- **默认状态**：隐藏，通过工具栏按钮显示

#### 3.2.3 Pairing Pane（P0 必须）

- **用途**：显示配对列表，用于查看/管理飞行配对
- **左侧固定列**：
  - 机型（Fleet）
  - 飞行时间（Block Hours）
  - 配比（Composition）：
    - 满配显示：`FCN(2)FFO(2)`（黑色）
    - 未满显示：`FCN(1:0)FFO(1:0)`（红色数字表示 Fill=0）
- **右侧甘特图区域**：显示每个 Pairing 的时间跨度和航段

#### 3.2.4 Flight Pane（P0 必须）

- **用途**：显示航班列表，按机尾号分组
- **左侧固定列**：机尾号（RegNo）、机型（Fleet）
- **右侧区域**：航班块，颜色按配比状态：
  - 满配：绿色
  - 未满：蓝色
  - 取消：斜线标记或黑紫色

### 3.3 Pane 布局管理

| 功能 | 优先级 | 说明 |
|------|--------|------|
| Pane 显示/隐藏 | P0 | 工具栏按钮控制每个 Pane 可见性 |
| Pane 高度调整 | P0 | Pane 之间横分隔条可上下拖拽 |
| 隐藏时自动撑满 | P0 | 其他 Pane 自动占满剩余高度 |
| 左侧面板宽度调整 | P0 | 竖分隔线可左右拖拽，所有 Pane 同步 |
| 默认显示 | P0 | 打开时默认显示 Roster 主 + Pairing |
| Pane 浮动 | P2 | 可选：支持 Pane 浮动窗口 |

### 3.4 交互操作

#### 3.4.1 拖拽操作（P0 必须）

| 源 Pane | 目标 Pane | 操作说明 |
|---------|-----------|---------|
| Roster 主 → Roster 主（不同 Crew） | 移动任务到另一个 Crew |
| Roster 主 → Roster 副 | 移动任务到副 Pane 的目标 Crew |
| Roster 副 → Roster 主 | 移动任务到主 Pane 的目标 Crew |
| Roster 内同 Crew | 交换两个任务 |
| Pairing Pane → Roster | 分配 Pairing 给 Crew |
| Flight Pane → Roster | 直接分配航班给 Crew |
| Flight Pane → Pairing Pane | 将航班添加到 Pairing（建环） |

#### 3.4.2 选中与标记

| 功能 | 样式 | 说明 |
|------|------|------|
| 选中任务 | 虚线边框 | 点击任务块选中 |
| 法规违规 | 小铃铛图标 + 颜色 | severity 1-2 黄色，3 橙色，4-5 红色 |
| Hover | 状态栏显示详情 | 任务信息或 Crew 基础信息 |

#### 3.4.3 右键菜单（P1）

- 根据航班定位对应 Pairing
- 根据 Pairing 定位对应 Roster
- 编辑、删除任务
- 后续开发时细化

#### 3.4.4 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Z | Undo |
| Ctrl+Shift+Z / Ctrl+Y | Redo |
| Escape | 取消选中 |
| Delete | 删除选中任务 |
| Ctrl+滚轮 | 缩放时间轴 |

### 3.5 汇总条（P1）

- **位置**：Header 下方，时间轴上方
- **功能**：按任务类型统计当天执行人数
- **显示**：每天一列，颜色块按任务类型百分比堆叠高度
- **交互**：点击某天弹窗，树形统计：
  - Root 1：Crew 总数 → 按 Rank 分层统计
  - Root 2：Assignment 任务数量统计

### 3.6 筛选与加载

#### 3.6.1 筛选弹窗

| 筛选维度 | 说明 |
|---------|------|
| 日期范围 | Start Date / End Date |
| Rule Set | 法规集合选择（决定检查哪些法规） |
| Rank | 职级多选（CA/FO/PU/FA） |
| Crew Base | 基地多选 |
| Fleet | 机队多选 |
| Crew Fleet | 机组机队资质多选 |
| Flight Fleet | 航班机队多选 |

#### 3.6.2 筛选记忆（P2）

- 不需要保存多个方案
- 需要记忆功能：下次打开自动恢复上次的筛选条件（localStorage）

### 3.7 法规检查（M1 与 M2 交互）

| 场景 | 行为 |
|------|------|
| 触发时机 | Gantt 上任何任务修改即时触发 |
| 不可违反法规 | 阻止本次修改操作 |
| 可违反法规 | 允许继续，显示告警标记 |
| 告警显示 | 任务块上小铃铛图标 + 左侧 Crew Header 也有标记 |
| 检查范围 | 按用户选择的 Rule Set 内的法规条目检查 |

### 3.8 排班发布

#### 3.8.1 计划发布

- 月度发布下月排班计划（如每月 20 号发布下月计划）
- 发布后机组可在 App 上查看排班

#### 3.8.2 动态实时发布

- 当前月班表调整后，系统识别出被调整的班表
- 动态发布将变更推送给机组
- 未发布前，机组仍看到上一版（计划发布版本）

### 3.9 Undo/Redo（P0 必须）

- 所有 Gantt 操作支持撤销和重做
- 操作历史栈
- Ctrl+Z / Ctrl+Shift+Z

### 3.10 缩放

支持 6 级时间轴缩放：

| 级别 | 显示粒度 |
|------|---------|
| 1h | 每小时一格，200px/小时 |
| 6h | 每6小时一格，40px/小时 |
| 12h | 每12小时一格，20px/小时 |
| 1d | 每天一格，10px/小时 |
| 3d | 每3天一格，4px/小时 |
| 7d | 每7天一格，2px/小时 |

## 4. M2 法规引擎模块

### 4.1 法规依据

CCAR-121-R5（中国民用航空运输承运人运行合格审定规则）

### 4.2 法规类型

#### 4.2.1 计算类法规（Calculator）

纯计算，输出数值，为检查类法规提供数据。

| 类别 | 规则代码 | 说明 |
|------|---------|------|
| FDP | max_fdp | 飞行值勤期计算（按航段数+开始时间查表） |
| FDP | fdp_extension | FDP延长计算（机长批准） |
| FDP | split_duty_fdp | 分裂值勤期FDP |
| 飞行时间 | flight_time_single | 单次飞行时间 |
| 飞行时间 | flight_time_cumulative | 累计飞行时间（7d/28d/90d/365d） |
| 值勤时间 | duty_time | 值勤期时长 |
| 休息时间 | rest_time | 值勤间休息时间 |
| 疲劳 | fatigue_risk_score | 疲劳风险评分 |
| 疲劳 | circadian_disruption | 昼夜节律扰乱指数 |

#### 4.2.2 检查类法规（Checker）

依赖计算结果，判断 pass/fail。

| 类别 | 规则代码 | 说明 |
|------|---------|------|
| FDP | max_fdp_check | FDP 不超过查表上限 |
| 飞行时间 | max_flight_time_check | 单次/累计飞行时间不超限 |
| 值勤 | max_duty_period | 最大值勤时间 |
| 值勤 | max_consecutive_duty | 最大连续值勤天数 |
| 休息 | min_rest_between_duty | 值勤间最小休息 |
| 休息 | min_rest_weekly | 周最小休息 |
| 增配 | augmented_fdp | 增配机组FDP上限 |
| 资质 | aircraft_type_rating | 机型资质检查 |
| 资质 | airport_qualification | 机场资质检查 |
| 资质 | recency_check | 近期经历检查 |
| 资质 | medical_validity | 体检有效期 |
| 组成 | min_crew_composition | 最低机组组成 |

### 4.3 法规配置层级

```
rule_template（预置算法，代码实现）
  ↓
rule_instance（具体法规实例 + JSONB params，如 FDP 查表数据）
  ↓
rule_group_item（集合项，启用/禁用 + 参数覆盖）
  ↓
rule_group（法规集合，GANTT/PO/RO/PBS 各自选择）
```

### 4.4 FDP 查表规则（核心示例）

根据航段数和值勤开始时间（当地时间）查表获取最大 FDP：

| 航段数 | 06:00-13:59 | 14:00-17:59 | 18:00-21:59 | 22:00-05:59 |
|--------|-------------|-------------|-------------|-------------|
| 1 | 13:00 | 12:30 | 12:00 | 11:00 |
| 2 | 12:30 | 12:00 | 11:30 | 10:30 |
| 3 | 12:00 | 11:30 | 11:00 | 10:00 |
| 4 | 11:30 | 11:00 | 10:30 | 9:30 |
| 5+ | 11:00 | 10:30 | 10:00 | 9:00 |

> 此表通过 rule_instance.params JSONB 参数化配置，不硬编码

### 4.5 法规违规严重级别

| 级别 | 名称 | 处理 | 颜色 |
|------|------|------|------|
| 1 | Info | 仅提示 | 黄色 |
| 2 | Warning | 提示，允许操作 | 黄色 |
| 3 | Caution | 需确认后继续 | 橙色 |
| 4 | Critical | 阻止操作 | 红色 |
| 5 | Fatal | 强制阻止 | 红色 |

### 4.6 两种使用模式

- **npm 包**：live-server / pbs-server 直接 import，零网络延迟
- **HTTP 服务**：PO/RO 引擎通过 REST API 调用

## 5. M3 PO 配对优化模块

### 5.1 功能概述

将航班自动组成最优飞行配对（Pairing），即航班→配对的组环过程。

### 5.2 使用场景

- 每月运行 3-5 天
- 排班员/优化操作员触发
- 结果审核满意后回写至 Live 系统

### 5.3 优化目标

```
minimize(
  w1 × 总配对数          # 最少配对
  w2 × 总死飞数          # 最少空驶
  w3 × 总值勤时间        # 最少值勤
  w4 × 软约束惩罚        # 偏好满足
)
```

权重 w1-w4 参数化，各航司可独立调整。

### 5.4 约束条件

| 类型 | 约束 | 说明 |
|------|------|------|
| 硬约束 | 航班覆盖 | 每个航班恰好属于一个配对 |
| 硬约束 | 航线连接 | 同一 duty 内到达机场=下一航段出发机场 |
| 硬约束 | 最小连接时间 | MCT（Minimum Connection Time） |
| 硬约束 | 最大 FDP | 从法规配置读取 |
| 硬约束 | 最小休息 | duty 间最小休息时间 |
| 硬约束 | 基地回归 | 配对从基地出发+返回基地 |
| 硬约束 | 连续值勤天数 | 不超过法规上限 |
| 软约束 | 短配对偏好 | 偏好较少天数的配对 |
| 软约束 | duty 均衡 | 偏好均匀的 duty 分布 |
| 软约束 | 等待时间 | 惩罚长时间地面等待 |

### 5.5 输入/输出

- **输入**：日期范围、航班列表、法规配置、基地机场、权重参数
- **输出**：配对列表（每个配对包含多个 duty，每个 duty 包含航段）+ KPI

### 5.6 场景管理

- 支持创建多个优化场景
- 场景间 KPI 对比
- 选择最优场景回写 Live

## 6. M4 RO 排班分配模块

### 6.1 功能概述

将配对（Pairing）分配给合适的机组成员，即配对→机组的分配过程。

### 6.2 使用场景

- 在 PO 完成后运行
- 每月运行 3-5 天
- 结果审核满意后回写至 Live

### 6.3 优化目标

```
minimize(
  w1 × 未分配配对数      # 最少遗漏
  w2 × 工时方差          # 工时均衡
  w3 × 基地偏好惩罚      # 基地匹配
  w4 × 死飞成本          # 减少空驶
  w5 × 机组偏好惩罚      # PBS 结果参考
)
```

### 6.4 约束条件

| 类型 | 约束 | 说明 |
|------|------|------|
| 硬约束 | 资质匹配 | 机型、航线、机场资质 |
| 硬约束 | 时间冲突 | 同一机组不能同时飞两个配对 |
| 硬约束 | FDP 合规 | 考虑已有排班累计 |
| 硬约束 | 飞行时间 | 7d/28d/90d/365d 不超限 |
| 硬约束 | 最小休息 | 配对间休息满足要求 |
| 硬约束 | 机组组成 | 每个配对满足组成要求（如 2CA+2FO+4FA） |
| 硬约束 | 连续值勤 | 不超过法规上限 |
| 软约束 | 工时均衡 | 同级别机组工时方差最小 |
| 软约束 | 基地匹配 | 偏好分配到机组所在基地出发的配对 |
| 软约束 | 机组偏好 | 可选，来自 PBS 竞标结果 |

### 6.5 KPI 指标

| 指标 | 说明 |
|------|------|
| assignment_rate | 分配率（已分配/总配对） |
| flight_hours_std_dev | 飞行小时标准差（公平性） |
| base_match_rate | 基地匹配率 |
| total_deadheads | 死飞数量 |

## 7. M5 PBS 竞标系统

### 7.1 功能概述

PBS（Preferential Bidding System）允许机组成员根据个人偏好提交排班申请，系统按资历优先级自动分配。

### 7.2 竞标结构（四层）

```
pbs_bid（主记录：每个机组/每期/每个上下文一条）
  ↓
pbs_bid_layer（层级：最多24层，层1优先级最高）
  ↓
pbs_bid_group（条件组：组内条件 OR 关系）
  ↓
pbs_bid_condition（条件：组内条件 AND 关系）
```

### 7.3 竞标类型

| 类别 | ID范围 | 类型数 | 举例 |
|------|--------|--------|------|
| Pairing（航线偏好） | 101-130 | 30 | 指定航线、机场、时间段 |
| DaysOff（休息偏好） | 201-206 | 6 | 指定休息日、连续休息 |
| Reserve（待命偏好） | 301-302 | 2 | 待命日期偏好 |
| Line（排班行偏好） | 401-407 | 7 | 工时、航段数偏好 |

### 7.4 竞标上下文

- **Default**：每月重复使用的模板
- **Current**：当期特定偏好（优先级高于 Default）

### 7.5 分配流程

1. 竞标期打开（`roster_period.pbs_*` 申请窗口内）
2. 机组提交偏好（pbs_bid: SUBMITTED）
3. 竞标期关闭（CLOSED）
4. 系统按资历排序，逐人逐层尝试满足偏好
5. 生成分配结果（pbs_award_result + pbs_award_item）
6. 发布结果（PUBLISHED）

### 7.6 三端界面

| 端 | 技术 | 功能 |
|----|------|------|
| pbs-server | Fastify + TS | 竞标 CRUD + 分配算法 + JWT 认证 |
| pbs-portal | React 19 | Web 端竞标界面 |
| pbs-app | React Native + Expo | 移动端竞标 + 查看排班 |

### 7.7 安全要求

- 独立用户系统（pbs_user ≠ 系统内部用户）
- RSA 加密密码传输、bcrypt 哈希存储
- JWT + token_version 管理
- 支持 5000 并发机组

## 8. 通用功能

### 8.1 参数化

| 层级 | 存储 | 说明 |
|------|------|------|
| 系统参数 | dictionary 表（parent_code='SYS_PARAM'） | 全局开关、阈值 |
| 功能配置 | dictionary 表（parent_code='FUNC_CONFIG'） | 模块开关 |
| 航司参数 | dictionary 表（按 schema 隔离） | 航司独立配置 |
| 法规参数 | rule_instance.params JSONB | 法规阈值 |
| 优化参数 | PO/RO 配置 | 优化权重、约束开关 |
| UI 参数 | dictionary + 前端配置 | 下拉选项、显示规则 |

**核心原则**：禁止硬编码业务常量，所有值从配置读取。

### 8.2 多航司部署

- PostgreSQL Schema 隔离（schema 名 = 航司二字码小写）
- 新航司上线流程：创建 schema → 执行建表 → 执行种子数据 → 配置参数
- 零代码修改

### 8.3 国际化

- 默认语言：英语
- 支持中英文切换
- UI 文本通过 i18n Provider 管理

### 8.4 权限系统

- 多级权限：菜单级 + 按钮级 + 数据级
- Profile（权限模板）→ User（绑定多个 Profile）
- 数据权限按 Base/Fleet 范围控制

### 8.5 预警系统

- 10 种预警类型：资质/证件/执照/体检/飞行时间/FDP/休息/疲劳/护照/近期经历 到期预警
- 可配置提前天数
- 通知模板

### 8.6 性能要求

| 场景 | 要求 |
|------|------|
| Gantt 数据加载+法规检查+界面渲染 | ≤ 1 分钟 |
| 单次法规检查响应 | ≤ 500ms |
| PBS 并发竞标 | 支持 5000 人 |
| PO 优化（一个月航班） | ≤ 5 分钟 |
| RO 分配（一个月配对） | ≤ 10 分钟 |
